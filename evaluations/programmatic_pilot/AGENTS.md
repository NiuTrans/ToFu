# Diagnostic programmatic-calling pilot

`workloads.py` owns the frozen synthetic world, read tools and exact oracles;
`runner.py` owns paired input identity and evidence retention.
`adaptive_workloads.py` owns the separate observed-dependency/semantic-join pack;
`declared_workloads.py` owns decoded-return schemas, cursor pagination and complete-source proof.
`workload_pack` selects the packs without changing existing identities. Read `README.md`.

Keep both arms identical except program availability. Preserve direct access,
complete baseline pagination and the semantic/small-result controls. Adoption
must come from native program records, never a prompt requirement.

Use the public production AgentRuntime. Substitute only model transport in
tests; never introduce an evaluation agent loop or interpreter. Live execution
requires the explicit CLI flag and access envelope. This pilot cannot promote
a release. Verification is named in `README.md`.
