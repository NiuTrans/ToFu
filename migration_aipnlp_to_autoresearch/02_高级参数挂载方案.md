# 文件 02 · 高级参数挂载方案

> 回答"`.bashrc` 要读 nlp-sh02 / nlp-hl02 / mlp-ckpt 的数据，迁移怎么办"。
> **实测更正**：`.bashrc` 本身**不读**这三个盘；它的路径全在 aipnlp 个人空间。这三个盘是**代码/训练脚本里的硬编码数据路径 + hope 挂载配置**。下面按真实依赖给方案。

## 一、dolphinfs 权限（容器挂载的根本）

新容器选 **dolphinfs权限 = 个人**（文件 01）。效果：
- 读：项目组 dolphinfs 全部文件（与项目组权限相同）。
- 写：仅你的个人目录 `/Users/your-username`。
- 平台**默认新建**该个人目录，无需手动建 `hadoop-autoresearch`。

## 二、高级参数怎么改

旧 `cpu_rjh` 高级参数含：
```
pc.use.dolphinfs=true
pc.use.hdfs.fuse=true
pc.use.dolphinfs.users=your-user        # ★ 退出 aipnlp 后失效，必须删/改
pc.shm.size.bytes=107374182400
```

**新容器建议**：
```
pc.use.dolphinfs=true
pc.use.hdfs.fuse=true
pc.use.dolphinfs.users=hadoop-nlp-sh02,hadoop-nlp-hl02,hadoop-mlp-ckpt   # 只读引用共享盘（见下）
pc.shm.size.bytes=107374182400
```
- 不再挂 `your-user`。
- 是否能把 `hadoop-nlp-sh02 / nlp-hl02 / mlp-ckpt` 作为 `pc.use.dolphinfs.users` 挂载，**取决于这些盘是否允许 autoresearch/个人访问**——见文件 05 待确认项 A。若不允许，去掉对应项，代码里改从个人目录读。

## 三、三个共享盘的真实用途与替代

| 盘 | 现状（实测） | 代码里的用途 | 迁移后 |
|---|---|---|---|
| `hadoop-nlp-sh02` | 存在；17 个子目录 | 训练数据集（fineweb-edu 等）、模型 config/输出（`BD3LM` 等），311+ 处硬编码 | ① 若能只读挂载→代码路径不用改；② 否则把要用的数据 rsync 到个人目录，并改代码路径 |
| `hadoop-nlp-hl02` | 存在；3 个子目录 | 同类数据/模型引用 | 同上 |
| `hadoop-mlp-ckpt` | 存在；206 个子目录（共享 ckpt 区） | hope 训练 ckpt 读写（`afo.dolphinfs.otherusers` 挂载） | 训练任务里继续按 `afo.dolphinfs.otherusers` 挂载（与容器挂载独立）；**退出 aipnlp 后 ckpt 区权限需确认** |

> 你的容器里 hope 任务已通过 `afo.dolphinfs.otherusers = your-user,hadoop-mlp-ckpt` 挂载——这是 **hope 任务侧**的挂载，**与 CodeLab 容器的高级参数是两套**。迁 hope 训练时改 `.hope` 文件里的这一行（把 `your-user` 换成新组/个人盘），而不是改容器。

## 四、`.bashrc` 实际需要的路径（这些都在个人空间，rsync 带走即可）

| 变量/路径 | 旧值（aipnlp 个人空间） | 说明 |
|---|---|---|
| `MAMBA_ROOT_PREFIX` / miniforge3 | `…/INS/your-username/miniforge3` | conda 环境（tofu/sglang 等） |
| `HF_HOME` | `…/your-username/.cache` | HF 模型缓存（GB 级，可重下） |
| `RUSTUP_HOME` | `…/your-username/.rustup` | rust 工具链（重装更稳） |
| `CARGO_HOME` | `…/your-username/.cargo` | cargo |
| `HOPE_HOME_DIR` | `…/INS/your-username/hope` | hope 客户端配置 |
| `NLTK_DATA` | `…/INS/your-username/nltk` | nltk 数据 |
| 入口 `login.sh` | `…/INS/your-username/login.sh` → source 个人 `.bashrc` | 见文件 03 迁移 |

→ 这些**都不依赖 nlp-sh02 / nlp-hl02 / mlp-ckpt**，rsync 个人空间即可还原。
