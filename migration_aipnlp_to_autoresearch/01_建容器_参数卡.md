# 文件 01 · 建容器参数卡（CodeLab 表单）

> 平台：https://mlp.internal.example.com/ml/#/codeLab/list → 新建容器。照学城 SOP（doc 2785659171）+ 你的截图核对。

## 表单逐项

| 字段 | 填法 | 说明 |
|---|---|---|
| 容器名称 | 默认（`your-username的CodeLab…`）或自取 | 建议自取如 `ar-cpu-rjh`，便于和旧 `cpu_rjh` 区分 |
| **项目组** | **`autoresearch`** | 截图证实下拉含 `autoresearch`（与 `aipnlp` 并列）。★ 必选，否则仍落在 aipnlp |
| **挂载 dolphinfs** | 选 **hadoop 权限** 那一项 | 只有选它，下方才出现「dolphinfs权限」字段 |
| **dolphinfs权限** | **个人** | ★ 核心：平台默认新建 `/mnt/your-fs` 作为个人目录，**无需手动建 hadoop-autoresearch** |
| 使用权限 | 个人独享（自动锁死） | 选「个人」后强制个人独享，正常（SOP FAQ Q2） |
| 环境镜像 | 自定义镜像，复用旧镜像名 | 见下"镜像" |
| GPU | 不需要（迁 cpu_rjh 环境） | 如需 GPU 训练另开容器 |
| 队列 | 选 autoresearch 项目组下的队列 | 下拉按项目组过滤；选与 aipnlp 无关的 autoresearch 队列 |
| 资源配置 | 参照 `cpu_rjh`：**60核 CPU / 210G 内存** | 见下"资源配置" |
| **高级参数** | **删除/替换** `pc.use.dolphinfs.users=your-user` | ★ 必须改：默认挂 aipnlp，退出后即失效。替换方案见文件 02 |

## 镜像（重要、省事）

环境类容器**无需"复制镜像"**，新建时直接填同一个镜像名即可：

- 迁 `cpu_rjh` 环境用：`hdp-mlp_training_cuda12.2_python2.7_glibc2.28_636c2ca6`
- `cpu_rjh` 是 `usePersistingRootfs=false`，不在"需导出镜像层"之列；环境里装的东西都在个人空间（rsync 带走），不在镜像层。
- 只有当你有 `usePersistingRootfs=true` 且在容器内改了系统层的容器，才需要单独处理镜像——`cpu_rjh` 不属于这种。

## 资源配置（对齐 cpu_rjh）

| 项 | 值 |
|---|---|
| CPU | 60 核 |
| 内存 | 210 G |
| GPU | 0 |
| 共享内存 shm | 按需在高级参数设 `pc.shm.size.bytes`（旧值 107374182400 = 100G） |

## 建容器后必做

1. 记录新容器的**个人目录实际路径**（进容器 `echo $HOME`、`ls /mnt/your-fs` 确认），文件 03 的 rsync 目标以它为准。
2. 验证 `.bashrc` 链能在新容器加载（文件 03 验证步骤）。
