How to call this relay

Point any OpenAI- or Anthropic-compatible SDK at this base URL with your Tofu API key as the bearer token:

# OpenAI Python SDK
from openai import OpenAI
client = OpenAI(
    base_url="LOADING…/v1",
    api_key="tofu_live_..."
)
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "hi"}],
)
print(resp.choices[0].message.content)
