# Knowledge HTML verification

`lib/knowledge/html_text.py` owns the parser; `extractor.py` is a thin benchmark
view. `reference.py` loads the pre-promotion function from immutable Git source
so changing production cannot turn differential checks into self-comparison.
Preserve hidden content, text-node whitespace, entities, headings, tables and
malformed recovery exactly. Run `check.py`, actual knowledge tests, `measure.py`
and fresh-process `cold.py`; never promote a parser microbenchmark as complete
PDF/web/batch/cancellation/storage admission. Results stay outside Git.

`durable.py` privately binds the actual upload facade to an owned native corpus;
never replace production globals or the running backend. `check_durable.py`
verifies exact content, receipt replay, owner denial, rollback, reopen and offline
integrity before `durable_measure.py` measures uploads and content readback.
Require the loaded library's compiled source identity to match this checkout;
latency and memory workers must agree on fixture, output and build witnesses.

`upload_phases.py` / `upload_phases_measure.py` observe actual article upload
stages through private bindings. Keep phase vectors aligned with measured samples;
warmup, cold and reopen checks are excluded. Nested totals are not additive, and
instrumented profiles cannot waive any original latency/memory rejection.

`token_projection.py` is an unpromoted per-call token-work candidate. Its
immutable reference comes from `f2ea9f0ea`; both upload arms retain current fast
HTML. Verify `check_tokens.py` before `token_measure.py`. Preserve term order,
length/cap rules, bounded memo ownership and all canonical native upload faults.

`native_profile_measure.py` uses fresh profiler off/on/on/off workers and the
current immutable token baseline in all trials. Reconcile every on-trial native
ledger before attribution. Keep profile cold/warmup scope, background CPU, nested
spans and native-local sample numbers distinct from timed upload observations.

The shared owned native harness accepts an explicit positive `owner_user_id`;
default HTML fixtures retain owner 1. Run `check_durable.py` after changing this
boundary; context fixtures bind their declared owner without changing live auth.

`interruption.py` kills/joins only an owned producer after its commit barrier,
then cold-recovers the original authority and retries by digest. Read README.md
for its receipt-interruption scope; this is not an HTTP/pre-commit cancel API.
`check_ingest_domain.py` covers native PDF/mixed/large input alongside HTML.
Verify checks/default-owner neighbor before `domain_measure.py` small/full runs.
`fixture_pdf.py` reproduces the frozen PDF; preserve source bytes and admission0.
