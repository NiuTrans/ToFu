本机控制

让 AI 读取并操作你自己的设备。两项能力互相独立，可分别开启。

浏览器标签页 尚未安装

读取你已打开的标签页内容，并代你点击、填表单、切换页面。

下载扩展并解压，然后在 Chrome / Edge 里打开扩展管理页 → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压出的文件夹。

Chrome 142+ 可能反复弹出「访问本地网络设备」

从 Chrome 142 起，访问本地网络的网页会逐站弹出权限请求，多标签搜索时需反复点击。扩展无法代为授权，请用以下任一方式关闭提示：

方式一（最快）：打开 chrome://flags/#local-network-access-check → 设为 Disabled → 重启 Chrome。

方式二（持久）：放置一个 Chrome 托管策略文件，内容为：

{ "LocalNetworkAccessAllowedForUrls": ["*"] }
