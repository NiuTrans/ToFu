# HTTP transport guidance

This package owns shared HTTP clients, inbound body admission, compatibility
middleware, compression, structured HTTP errors and request timing. The domain
map is `docs/modules/infra_runtime.md`; transport policy remains independent of
routes and storage implementations. `lib/app/app_assembly.py` registers inbound
owners, and `client.py` owns lazy outbound sessions and joined shutdown.

`plugin_frontend.py` registers the public async `tofu_plugin_assets()` template
helper. It offloads manifest reads to the existing `lib/vite_assets.py` owner;
entry identity belongs to `frontend/authoring-inputs.json`. Verify native HTTP
asset delivery and the browser journey in the plugin frontend tests.

Preserve streamed request bodies, cancellation, typed errors and response byte
accounting. Run the HTTP tests under `tests/server/`, then application assembly,
server shutdown and frontend/API serving tests.

`websocket_fairness.py` adapts each owned Hypercorn WebSocket before app entry;
large encoding borrows the existing executor and joins before stream release.
Verify `test_websocket_send_fairness.py` and Hypercorn connection/shutdown tests.

`generated_frontend_vendor.py` is generated by
`scripts/frontend_vendor_assets.mjs` from the npm lock and installed assets;
`frontend_vendor.py` verifies the delivered bytes without Node or a live store.
Report exports consume its CDN integrity metadata. Verify vendor generation,
drift detection and standalone math browser tests; edit the generator, not the
generated module.

`ui_languages.py` exposes the frontend-owned UI language manifest
(`frontend/src/i18n/languages.json`) to the request language cookie, the Vite
i18n digest and interface-language model output; it never keeps a second
language list. Verify `tests/i18n/test_derived_locales.py` and
`tests/i18n/test_i18n_lang_cookie_signal.py`.
