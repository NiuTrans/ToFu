# Long-task surface design study

This directory owns a reviewable interaction proposal, not runtime behavior.
Read `README.md` for observed evidence, decisions and implementation gaps.
`index.html`, `prototype.css`, and `prototype.js` are the editable sources.
The prototype uses local theme/font assets and in-memory synthetic fixtures;
never connect its controls to production commands or copy live user data here.
`previews/` and `verification.json` are browser evidence, not source owners;
refresh them after changing the source and repeat the affected journeys.

Verify the two surfaces in a real browser, including synchronized answers,
scoped messages, source preview return, interruption and mobile overflow.
Product implementation belongs to the existing owners named in the README.
